# core 测试

```bash
npm run test:core
```

覆盖：

- 真实 Core 与假 Core 共享同一 READY 与 `/api/v1/info` 模型，CSP、安全响应头、版本、nonce 与测试控制 socket。
- 会话令牌与壳侧共享金样值（跨语言 HMAC 一致性）。
- 节点归一化（稳定路径键、归一化 bounds、DTD 拒绝、无 bounds 节点继承）。
- XPath（语法预检、结果映射、长度限制、零命中保留）。
- 摘要确定性、交互元素覆盖与选择器真实命中数。
- 六类诊断检出、严重度排序、density 换算与无 density 降级。
- 设置原子写入、字段白名单与范围校验。

## 契约与安全

- 请求体上限 1MB；写接口必须携带会话令牌；只读拦截返回 `READ_ONLY_MODE` 并写审计。
- XPath 表达式最长 512 字符，隔离线程 300ms 硬超时。
- 快照节点上限 3000、深度 128；文本与属性限长。
