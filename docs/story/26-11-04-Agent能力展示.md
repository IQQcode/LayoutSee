# Agent 能力展示：首启弹窗与设置 Agent 分区

日期：2026-11-04。设计事实源：`specs/22_8_agent_intro/doc.md`。

## 目标

让装完 LayoutSee 的用户看见 Agent 能力：首次打开弹窗提示（仅首次），设置页新增「Agent」分区常驻展示。

## 范围

- Core settings 新键 `agentIntroSeen`（contracts 零改动）+ 单测。
- `AgentIntroDialog.jsx`（全局挂载，HostBridge 会话就绪后判定）+ `agentSkills.js` 共用文案数据。
- `SettingsPage.jsx` 新增 Agent 分区：状态 chips（Core 连接 + MCP 动态工具数）、三张 Skill 卡（含可复制示例提示词）、MCP 端点指引。
- MorphIcons 新增 bot/scanEye/wrench/sparkles/smartphone 五个 glyph；app.css 少量新类。
- 文案润色定稿：标题「让 AI 读懂你的界面」+ 三个 Skill（layout-see·布局感知 / layout-env·一键配置 / layout-lookin-server·iOS 接入）。

## 验收标准

1. 弹窗仅首次展示：关闭后 PUT `agentIntroSeen=true` + localStorage 兜底，刷新/重启不再弹；no_session 只读模式不弹。
2. 设置 Agent 分区卡片/chips/复制框在深浅两主题下渲染正确。
3. `npm run test:unit` + `npm run lint` 全绿。

以上均已在 dev:web + 浏览器自检中验证（`LAYOUTSEE_DATA_DIR` 临时目录隔离，未污染真实 settings）；DMG 形态观感由用户最终确认。

## 涉及仓库 / 依赖

- `repos/core`（settings 两行 + 单测）、`repos/web`（弹窗/设置/图标/样式/测试）；contracts/mac/plugins 零改动。
- 依赖事实：HostBridge 会话订阅范式（KernelBanner）、Dialog/CopyButton/StatusPill 现成组件、McpTab code-card 范式。
