# Story-0827 M0：契约与工程初始化

## 目标

在业务功能编码前建立可重复验证的跨进程契约和四工程底座，关闭 `technical-design.md` 中 M0 的完成定义。

## 已完成范围

- 根 npm workspaces 与统一的生成、检查、测试、构建脚本。
- `repos/contracts` 的 OpenAPI 3.1、JSON Schema 2020-12、兼容矩阵、正反夹具及 TypeScript/Pydantic 生成器。
- `repos/core` 的 loopback 启动、READY 行、info/health 接口与 Unix socket 可控假 Core。
- `repos/web` 的正式 Vite/React 构建入口与同源 Core 状态页。
- `repos/mac` 的严格 READY/info 身份校验和 M0 壳层占位制品。
- 对应 `source/` 三件套、依赖锁与生成物漂移检查。

## 验收命令

```bash
npm run lint
npm run typecheck
npm run test:unit
npm run build:all
npm run verify:artifacts
```

## 明确未进入范围

- 不迁移 prototype 的业务页面与静态交互。
- 不锁定 Electron、打包器、Playwright、PyInstaller 或 MCP SDK 版本。
- 不实现签名、公证、WebCodecs、生产 Core 进程守护；这些属于 M0.5 风险验证及后续里程碑。
