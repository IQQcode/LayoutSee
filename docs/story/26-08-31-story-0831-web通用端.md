# Story-0831 Web 通用端：浏览器成为一等宿主

## 背景

mac 桌面壳完成后，前端在浏览器里只剩「看设备列表 + 看画面」：会话令牌唯一来源是 `window.layoutSeeShell`，浏览器直接打开 `http://127.0.0.1:33299` 时令牌为 `null`，Core 的 `_require_session()` 会拒绝抓取快照、注入点击、切只读、存设置与日志上报。真正的阻塞点不是 UI 复刻，而是「会话 + 宿主能力抽象 + 开发链路」三件基础设施缺失。

本 Story 让浏览器与桌面壳对等，并参照 `source/uiautodev`（只读参考，未改动）的功能与手感补齐层级、包管理、终端三块能力。视觉一律按 `docs/DESIGN.md`，不复刻 uiautodev 界面。

## 已完成范围

- **会话与安全**：Core 托管首页时把会话令牌替换进 `<meta name="layoutsee-session">`（选 meta 而非内联脚本，因为 CSP 是 `script-src 'self'`）；`/api/**` 与 `/mcp/**` 增加 Host 与 Origin 双校验，读写都校验。这同时关闭了技术评审 4.3 要求但未落地的「Origin 白名单」，并防住 DNS rebinding。
- **宿主抽象**：`ShellBridge` 升级为 `HostBridge`，对外给 `kind`（shell / browser）与 `can` 能力清单，UI 按能力渲染。壳独有能力（保存对话框、打开目录、选 adb 路径、原生主题、进程控制）在浏览器下都有明确降级：Blob 下载、路径文本 + 复制、手工输入路径 + Core 校验、`matchMedia`、隐藏入口。不再有 `isElectron` 式环境嗅探。
- **开发链路**：`npm run dev:web` 一条命令解决 dev 下 `/api` 404 与令牌缺失两个问题；vite 代理转发时摘掉 `Origin`，让 Core 走无 Origin 放行分支。
- **层级**：XPath 支持按 `id / text / class` 生成（Core 的选择器候选新增机器可读的 `kind` 字段，前端不重写生成规则）；多命中渲染序号 chip 可逐个定位；工作台底部常驻状态栏显示分辨率、鼠标坐标与百分比、节点数、Core 版本。
- **包管理**：应用列表支持系统应用开关（两次 `pm list packages` 对比标记 `system`）、行内启动 / 停止 / 清除数据 / 卸载，高危动作统一二次确认，系统应用卸载直接禁用。
- **终端**：新增 `POST /api/v1/devices/{id}/shell`，命令整串作为**一个** argv 传给 `adb shell`，主机侧零 shell 拼接；只读模式全禁、会话必需、设备串行锁、输出 256KB 截断、超时默认 15s 上限 60s；审计只记命令长度与哈希，不落原文与 stdout。前端历史 100 条按设备隔离，上下键翻历史、Ctrl/Cmd+L 清屏、高危前缀二次确认。
- **契约**：补齐 shell、apps 查询参数、动作枚举说明、selectors `kind`、`paths`，以及此前一直未回填的 `ui-logs`、`window-size`、`media/stream`，`contracts:check` 恢复可信。

## 验收命令

```bash
npm run lint
npm run test:unit        # contracts 7 + mac + web 7 + core 82
npm run contracts:check
npm --workspace @layoutsee/web run build
npm run dev:web          # 浏览器真机联调入口
```

## 值得记住的几个判断

- **注入令牌必须配套 Origin/Host 校验**，否则等于降低安全水位：同机任何网页都能拿同源令牌打写接口。两者是一组，不能只做一半。
- **首页替换占位符后必须重算 `Content-Length`**，先算长度再替换会截断首页。
- **终端不做命令黑名单**。黑名单既拦不住（编码、变量、管道绕过）又破坏体验，安全边界交给只读门禁、会话校验、审计与超时；前端的高危二次确认是提醒而非边界。
- **只支持 loopback**。局域网 IP 既不可达（Core 只 bind 127.0.0.1），也会丢 secure context，`crypto.randomUUID`、剪贴板、WebCodecs 全部依赖它。
