# PRODUCT.md 产品设计上下文

LayoutSee 产品设计上下文的入口文档。**单一事实源是 PRD**，本文件只提供定位摘要与路由。

## 产品定位

LayoutSee 是面向移动开发与 AI 协同场景的 macOS 桌面应用：连接 Android / iOS / HarmonyOS 真机，提供实时投屏与操控、结构化 UI 层级抓取、语义摘要、布局异常诊断和 MCP 服务，把移动设备运行时视图转换为 Agent 可读、可定位、可操作的结构化资源。

**产品价值一句话**：

> LayoutSee 把「移动设备运行时视图」变成 Agent 可读、可定位、可操作的结构化资源，通过 MCP 无缝接入 AI 工作流，让 AI 开发移动应用时看得见、摸得着。

## 目标用户

| 用户类型 | 核心诉求 |
|---------|---------|
| 移动端开发工程师 | 快速看到画面 + 层级树，点哪查哪 |
| QA 工程师 | 稳定选择器、快照存档、回归 diff |
| AI Agent | 结构化、低 token、语义清晰的视图感知工具集 |
| 插件开发者 | 受限但够用的运行时 API |
| 团队管理员（V1.0） | 鉴权、占用管理、审计 |

## 关键概念

- **布局快照（LayoutSnapshot）**：一次视图抓取的完整结果，全系统唯一布局事实来源。
- **Node**：跨平台统一的视图节点契约（key / name / bounds / rect / properties / children）。
- **视图感知**：Agent 通过结构化节点树而非像素截图理解界面。
- **语义化布局摘要**：面向 LLM 的低 token 结构描述，元素带短引用 ref。
- **MCP**：以 SSE 方式按设备暴露能力给 AI 客户端。
- **内核（Core）/ 壳（Shell）**：本地设备接入与 API 服务进程 / 桌面客户端外壳。
