# LayoutSee Logo 设计提示词

本文是 LayoutSee Logo 生成、编辑和切图的视觉单一事实源。执行任务时先读取上方列出的视觉母版；母版与文字描述冲突时，以母版的轮廓、比例、渐变和字标位置为准。

## 1. 品牌表达

LayoutSee 将移动设备运行时视图转化为 Agent 可读、可定位、可操作的结构化资源。Logo 不直接描绘产品功能，而是用一个柔性、连续、可识别的字母 `M` 色带表达：

- 多端连接：左右支柱稳定承托整体结构；
- 布局流动：中央色带以连续曲率下沉并抬升；
- 精确与友好：粗壮等宽、圆润端点和克制构图；
- 品牌识别：高饱和连续渐变与黑色 `LayoutSee` 字标形成稳定组合。

品牌气质是 Apple 品质感与开发者工具的克制感：清晰、安静、精确、圆润，不堆叠功能隐喻。

## 2. 定稿结构

### 2.1 纯图形标志

图形是一个由宽色带构成的大写 `M`：

1. 左侧是一条粗壮竖直支柱，顶部以大圆角胶囊端点起笔，底部为完整圆角；
2. 色带从左上端向画面中央自然下沉，再向右上端平滑抬升；
3. 中央走势接近柔和的 S 形连续曲线，内外边缘平行，起点、中段和终点保持一致的视觉粗细；
4. 右侧是一条与左支柱同宽、同高、同圆角半径的竖直支柱；
5. 左右结构近似镜像平衡，中央最低点位于画面水平中心附近；
6. 所有连接处保持连续曲率，不出现尖点、硬折线、局部膨胀或突然收窄。

### 2.2 图形与字标组合

组合版在 M 的两条竖直支柱之间、中央色带下方放置字标：

- 文字严格为 `LayoutSee`，大小写固定，不带句点；
- 使用黑色、超粗、圆润、现代的无衬线字体；
- 字距紧凑但清晰，整体水平居中；
- 文字完整位于两条支柱之间，不触碰或覆盖彩色图形；
- 以小写字母 `y` 的最低可见像素作为文字底边；
- `y` 的最低点必须与左右支柱的最低点严格处于同一水平线。

## 3. 比例与安全区

以下数值来自当前透明母版，用于控制生成结果而非替代母版。

### 3.1 纯图形方形版

- 画布：1:1，透明背景；
- 图形横向范围：约 x=8.8%–91.1%；
- 图形纵向范围：约 y=18.4%–81.5%；
- 图形等比居中，不拉伸，不裁切；
- 四周保留透明安全区，小尺寸下仍能看清圆角和中央曲线。

### 3.2 图形与字标组合版

- 当前母版尺寸：1036×795，透明背景；
- 完整内容范围：约 x=4.5%–95.4%、y=4.5%–95.3%；
- 彩色图形范围：约 x=4.6%–95.3%、y=4.7%–95.2%；
- 黑色字标范围：约 x=24.7%–75.6%、y=80.9%–95.2%；
- 字标最低点和彩色支柱最低点均为 y≈95.2%，两者差值必须为 0px；
- 文字与左右支柱保持清晰间距，与中央色带之间保留呼吸空间。

## 4. 色彩与材质

### 4.1 渐变路径

使用连续、明亮、饱和但不发光的多色渐变：

| 区域 | 颜色走势 |
|------|----------|
| 左上圆角端点 | 亮粉色 |
| 左侧支柱与左半色带 | 粉色自然过渡到鲜红色 |
| 中央下沉段 | 红色过渡到红橙色 |
| 右上抬升段 | 橙色过渡到金黄色 |
| 右侧支柱上段 | 绿色 |
| 右侧支柱中段 | 青绿色到青色 |
| 右侧支柱下段 | 高饱和蓝色 |

建议渐变锚点可使用：亮粉 `#FF3B7F`、鲜红 `#FF1028`、橙红 `#FF4B0A`、橙色 `#FF8500`、金黄 `#FFD21A`、绿色 `#08A94F`、青色 `#08A5B5`、蓝色 `#155CFF`。生成时允许在相邻锚点间平滑插值，以视觉母版为最终标准。

### 4.2 表面与背景

- 图形为干净的平面色带，可保留极轻微的色彩柔化，但不使用立体材质；
- Web 主资产背景必须是真实透明 Alpha，不得把白底或棋盘格画进图片；
- macOS 应用图标是唯一例外：图标内部使用纯白 `#FFFFFF` 连续圆角底板，底板外保持真实透明 Alpha；
- macOS 白色底板不得带灰色、米色、透明灰、渐变、阴影、描边或环境光；
- 白色与深色背景只用于预览验收，不属于 Logo 像素；
- 字标固定为纯黑 `#000000`；深色界面如需使用组合版，应另行输出白色字标变体，彩色图形保持不变。

## 5. 生成提示词

### 5.1 纯图形透明版

```text
生成 LayoutSee 的纯图形 Logo。主体是一个由粗壮柔性色带构成的大写 M：左右两侧为等宽、等高的圆角竖直支柱，顶部和底部均为完整胶囊圆角。宽色带从左上端自然下沉至画面中央，再连续、平滑地抬升至右上端，整体接近柔和的 S 形走势。色带内外轮廓平行，起点、中段和终点保持完全一致的视觉粗细，所有连接处曲率连续。

颜色沿色带自然连续过渡：左上亮粉，左侧与左半段为粉红到鲜红，中央为红橙，右上为橙黄；右侧竖直支柱从上到下依次为绿色、青色和高饱和蓝色。颜色鲜明、平面、干净，不发光。

使用 1:1 正方形画布，图形等比居中，横向约占 82%，纵向约占 63%，四周保留透明安全区。只保留 M 图形，不包含文字。输出真正带 Alpha 通道的透明 PNG；图形外 Alpha=0，不绘制白底、黑底或棋盘格。
```

### 5.2 图形与字标透明组合版

```text
生成 LayoutSee 的完整组合 Logo。彩色 M 图形严格沿用纯图形版：左右支柱等宽等高，圆角一致；中央色带以等宽、连续曲率的柔和 S 形下沉并抬升；渐变由左侧亮粉和鲜红，经中央红橙，过渡到右上橙黄，右侧支柱再由绿色过渡到青色和蓝色。

在两条竖直支柱之间、中央色带下方放置准确文字“LayoutSee”，不带句点。使用纯黑色、超粗、圆润、现代的无衬线字体，字距紧凑，水平居中，文字不触碰两侧支柱或上方色带。以小写字母 y 的最低可见像素为文字底边，使它与左右彩色支柱的最低点严格处于同一水平 Y 坐标，像素差为 0。

保持当前母版约 1.30:1 的宽高关系，完整内容四周保留约 4.5% 透明安全区。输出真正带 Alpha 通道的透明 PNG；Logo 之外 Alpha=0，不绘制白底、黑底或棋盘格。
```

### 5.3 macOS 图标版

```text
基于 LayoutSee 的纯图形 M 标志生成 macOS 图标母版。使用 1024×1024 RGBA 画布，在画布中央放置一个连续、饱满、符合 macOS 图标轮廓的圆角方形底板。底板内部必须是完全均匀的纯白色 #FFFFFF，不得出现灰色、米色、透明灰、渐变、阴影、描边、光晕或环境反射；只有圆角底板外部为真实透明 Alpha=0。

将彩色 M 等比居中放在白色底板内，四周保留协调且一致的安全区。完整保留圆角端点、等宽柔性 S 形色带以及亮粉、红、橙、黄、绿、青、蓝的连续渐变，不添加文字或其他装饰。确保缩小到 16px 时仍能辨认 M 的外轮廓和中央下沉曲线。最终输出必须呈现“纯白圆角底板上的彩色 M”，不得依赖 macOS 自动补背景。
```

### 5.4 Web 横版与品牌展示版

```text
基于 LayoutSee 完整组合母版生成 Web 品牌 Logo。保留彩色 M 和内嵌黑色“LayoutSee”字标，保持文字位于两条支柱之间、中央色带下方。字母 y 的最低点与左右支柱最低点严格底对齐。裁掉无效空白，仅保留约 4.5% 透明安全区；输出透明 PNG，并按宽度等比导出 512px、1024px 和 2048px 三档。不得重排图形与文字，不得改变比例或渐变。
```

### 5.5 编辑约束

对现有 Logo 做局部修改时，在提示词末尾追加：

```text
这是对现有 LayoutSee Logo 的精确局部编辑。只修改已明确指定的区域；其余画布比例、M 图形尺寸、左右支柱位置、色带粗细、圆角、连续渐变、文字拼写、字号、字重和对齐关系保持不变。文字固定为“LayoutSee”，不带句点。背景保持真实透明。完成后检查：色带全程等宽、中央曲率连续、文字不碰图形、y 与左右支柱底边像素级共线。
```

## 7. 验收清单

- [ ] 纯图形在 3 秒内可识别为圆润、宽色带构成的 M；
- [ ] 中央色带走势柔和自然，内外曲线连续且全程等宽；
- [ ] 左右支柱等宽、等高，顶部和底部圆角一致；
- [ ] 渐变顺序为亮粉 → 红 → 红橙 → 橙黄，以及右支柱绿 → 青 → 蓝；
- [ ] 文字严格为 `LayoutSee`，无句点、无拼写或大小写变化；
- [ ] 文字为黑色超粗圆润无衬线，完整位于两条支柱之间；
- [ ] 小写 `y` 的最低点与左右支柱最低点的 Y 坐标差为 0px；
- [ ] PNG 使用真实 Alpha，透明区域不存在白底、棋盘格、散点、光晕或脏边；
- [ ] macOS 图标底板内部像素为纯白 `#FFFFFF`，没有灰色、渐变或阴影，圆角底板外 Alpha=0；
- [ ] 在纯白与纯黑背景上合成检查，彩色边缘均干净；
- [ ] 16px、32px、128px、512px 和 1024px 抽样检查无裁切、无变形；
- [ ] `.iconset`、`.icns`、Web PNG 与 `favicon.ico` 均可正常解析。
